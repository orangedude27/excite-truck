TP MSL reference snapshot
==========================

This directory is copied from:

  other_decomp_projects/tp/libs/PowerPC_EABI_Support/MSL/MSL_C/MSL_Common/

The files are reference material only. They are not listed in REXE01 splits.txt
and are not compiled by the project. Do not replace the active src/MSL files or
promote these files wholesale without checking REXE01 assembly, ABI, data
layouts, and auto-unit ownership.

Use this snapshot to port functions in bounded batches. TP is the primary
reference because it contains a complete Wii-era MSL implementation. Petari and
AF e+ remain useful cross-checks for version differences.
